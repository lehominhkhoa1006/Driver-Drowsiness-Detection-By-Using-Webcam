## Overview

This project presents a webcam-based driver drowsiness detection system developed as a group project for the Special Project (EL) course at Ho Chi Minh City University of Technology and Education (HCMUTE) during the 2023–2024 academic year.

The system monitors the driver's eyes in real time using computer vision and facial landmarks. The Eye Aspect Ratio (EAR) is calculated from the detected eye landmarks to determine whether the eyes remain closed for a prolonged period. When sustained eye closure is detected, the system activates a buzzer and displays a warning on the video stream.

The project was developed as a proof-of-concept prototype for camera-based driver monitoring, focusing on eye-state detection and real-time drowsiness warning.
